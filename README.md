# Feng Liu — Personal Mathematics Website

A single-file, GitHub Pages-compatible personal mathematics homepage.

## Structure

- Home
- Research
- Publications — grouped by year
- Preprints — grouped by year
- Talks
- Teaching
- Notes
- CV

Each paper entry is intentionally minimal: **title, authors, journal/venue**, plus expandable **Abstract** and **PDF** links. DOI and individual publication dates are not shown.

## Run locally

Open `index.html` directly in a browser.

## GitHub Pages

Create a repository such as `yourname.github.io`, upload `index.html` to the repository root, then enable GitHub Pages from the default branch and root directory.

To add PDFs, create `papers/publications/` and `papers/preprints/`, then update the corresponding links in `index.html`.
